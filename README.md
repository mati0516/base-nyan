# base-nyan

**猫の鳴き声 32 種をアルファベットに使う、バイナリ→テキスト符号化。**

ブラウザで試せます → **https://mati0516.github.io/base-nyan/**

Base32 が A〜Z と 2〜7 を使うところを、base-nyan は 32 の鳴き声を「数字」として使います。
ニャーが `0`、ンーが `31`。あとは 32 進数を書き下すだけ。

```
$ base-nyan encode "さくら"
ニャニャンナーニャーカカカミャウフシャニャニャニャンニャアミャンゴロンミャンニャーゴロゴロミャッ

$ base-nyan decode ニャニャンナーニャーカカカミャウフシャニャニャニャンニャアミャンゴロンミャンニャーゴロゴロミャッ
さくら
```

姉妹品：[base47](https://github.com/mati0516/base47)（47都道府県）

## Base32 に無い性質

### 1. 区切り文字が要らない

32 の鳴き声は、**どれも他の鳴き声の先頭になっていない**ように選んであります
（情報理論でいう**接頭符号**）。だから区切り無しで並べても、前から順に一意に読み切れます。

「ニャーン」や「ゴロ」が入っていないのはこのためです。
入れると「ニャー」「ゴロゴロ」と頭が重なって、`ニャーンナー` が `ニャーン|ナー…` なのか `ニャー|ンナー` なのか決まらなくなります。

区切りは読みやすさのために**足してもよい**だけです。`、` `！` `♪` 空白などは読み飛ばします。
（長音 `ー` は鳴き声の一部なので、base47 と違って区切りには使えません。）

```
ニャニャ、ンナー、ニャー、カカカ、ミャウ、フシャ、ニャニャ、ニャン、…
```

### 2. パディングが要らない

Base32 は末尾を `=` で最大 6 個埋めます。base-nyan は埋めません。
端数のバイト数と鳴き声の数が一対一に対応するので、**長さそのものが端数の情報を持ちます**。

| 端数 | 鳴き声 |
|---:|---:|
| 1 バイト | 2 |
| 2 バイト | 4 |
| 3 バイト | 5 |
| 4 バイト | 7 |
| 5 バイト | 8 |

`1`・`3`・`6` 回で終わる並びは存在しない ＝ **壊れた入力をその場で検出できます。**

### 3. ひらがなでも読める

`にゃにゃんなーにゃー…` と書いても `ニャニャンナーニャー…` と同じに読みます。

## 詰め方

**5 バイト（40 bit）を 32 進数 8 桁で書く**のを1ブロックとします。
32 = 2<sup>5</sup> なので、1鳴き声がちょうど 5 bit。無駄はありません。

| | |
|---|---|
| 1鳴き声あたりの情報量 | **5 bit** |
| 理論上限（log₂32） | 5 bit |
| 効率 | **100 %** |

（比較：base47 は 5.5385 / 5.5546 bit で 99.7%）

## 使う

### ブラウザ

`index.html` を開くだけ。ビルド不要・依存なし。

> ローカルで開く場合は、ES モジュールの都合で `file://` ではなく HTTP で配ってください。
> ```
> npx serve .      # → http://localhost:3000
> ```
> サーバ無しで開きたいときは `base-nyan.standalone.html`（`npm run build` で再生成）をダブルクリック。

### ライブラリ

```js
import { encode, decode, decodeText, MEOWS } from "./src/base-nyan.js";

encode("さくら");                       // "ニャニャンナーニャーカカカ…"
decodeText("ニャニャンナーニャーカカカ…"); // "さくら"

encode(pngBytes);                      // Uint8Array も渡せる
encode(pngBytes, { separator: "、" });  // 読みやすく区切る（デコードには不要）
decode("にゃにゃ！んなー♪にゃー …");      // 区切りもひらがなも読める
```

壊れた入力は `BaseNyanError` を投げます（何文字目かも持っています）。

### コマンドライン

```
$ base-nyan encode "さくら"
$ base-nyan decode ニャニャンナーニャーカカカ…
$ base-nyan encode -f photo.png --sep '♪' > photo.txt
$ base-nyan table                     # 32の鳴き声と桁の値
$ echo -n "hello" | base-nyan encode  # 標準入力から
```
