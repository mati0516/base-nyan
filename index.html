base-nyan

Base32 が A〜Z と 2〜7 を使うところを、猫の鳴き声 32 種を数字として使う符号化。 ニャーが 0、ンーが 31。あとは 32 進数を書き下すだけ。

5 バイト = 8 鳴き声 1鳴き声あたり 5 bit（理論上限の 100%） 区切り文字 不要 パディング 不要 ひらがなでも 読める

入力（文字列）0 バイト

出力（鳴き声）0 鳴き声

なぜ区切り文字が要らないのか

32 の鳴き声は、どれも他の鳴き声の先頭になっていないように選んであります。 「ニャーン」や「ゴロ」を入れていないのはこのためで、入れると「ニャー」「ゴロゴロ」と頭が重なります。 並びは前から順に一意に読み切れる ── 情報理論でいう接頭符号です。 長音「ー」は鳴き声の一部なので区切りには使えませんが、「、」「！」「♪」や空白は自由に挟めます。

桁の詰め方

5 バイト（40 bit）をひとかたまりにして、32 進数 8 桁に書き直します。 32 は 2 の 5 乗なので無駄は一切ありません。 端数は下の表のとおりで、長さ自体が端数の情報を持つためパディングは不要です。 1・3・6 回で終わる並びは存在しないので、壊れた入力はその場で分かります。

使い方

import { encode, decode, decodeText } from "base-nyan";

encode("さくら");        // "ニャニャンナーニャーカカカ…"
decodeText("にゃにゃんなーにゃーかかか…");  // ひらがなでも読める
encode(pngBytes, { separator: "、" });
$ base-nyan encode "さくら"
$ base-nyan decode ニャニャンナーニャーカカカ…
$ base-nyan encode -f photo.png --sep '♪' > photo.txt
